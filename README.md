## What's this?

A tiny static site: plain HTML, CSS and a pinch of JavaScript. No frameworks, no build step, nothing fancy. It has a pixel-art look with falling pixel snow (a vanilla-JS port of [React Bits' PixelSnow](https://reactbits.dev/backgrounds/pixel-snow), tweak it in `assets/pixel-snow.js`), a few chess vibes, and it works on phones and desktops.



Made by a first-year CS student who really wanted a nicer link than a Linktree.
